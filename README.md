## ✨ Project Overview
This project isn't just a functional e-commerce app; it's a deep dive into **Enterprise-level React Architecture**. Starting from a solid roadmap, I challenged myself to implement the latest industry standards, ensuring the codebase is maintainable, type-safe, and highly performant.

### 💡 Key Personal Enhancements (Beyond the Basics)
* **Tailwind CSS v4 Integration:** Completely rebuilt the UI using the latest version of **Tailwind** for a modern, performance-first design.
* **Advanced Carousels with Swiper.js:** Independently integrated **Swiper.js** to create a seamless, touch-friendly product browsing experience.
* **Pro-level UX Handling:** Designed and implemented custom **Loading Skeletons** and **Error Boundaries** to ensure a smooth user journey.

---

## 🛠️ Technical Stack & Tools
* **Core:** **React.js** + **TypeScript** (100% Type-Safe) 🛡️
* **State Management:** **Redux Toolkit (RTK)** + **Redux Persist** 💾
* **Styling:** **Tailwind CSS v4** + Responsive Design 🎨
* **Authentication:** Full **Auth & Auth** flow using **JSON Server Auth** 🔐
* **Navigation:** **React Router Dom** (with Protected Routes & Guards) 🚦
* **Validation:** **Zod** + **React Hook Form** ✅
* **API Client:** **Axios** with structured service layers 🌐
* **Interactive UI:** **Swiper.js** for high-performance sliders 🎠

---

## 🧩 Architectural Design Patterns
To ensure the app is scalable, I applied several professional patterns:
* **Container/View Pattern:** Decoupling business logic from UI components.
* **Atomic Design Principles:** Organizing components for maximum reusability.
* **Clean Code:** Utilizing **TS Alias Paths**, narrowing, and modular file structures.
